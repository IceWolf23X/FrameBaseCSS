Verified scope and progressive enhancement

Browser support

The fully enhanced target starts at Chrome/Edge 114, Firefox 125, and Safari 17. Automated tests exercise pinned Chromium, Firefox, and WebKit builds; minimum product versions remain feature-derived targets.

Features that set the baseline

color-mix()
Builds token-derived surfaces; unsupported declarations are ignored, so base colors and borders remain.
:has()
Adds parent-aware invalid and disabled styling; native control semantics still work without it.
Popover API
Native non-modal overlay enhancement. Use details or consumer behavior when older browsers matter.
dialog
Provides modal semantics and focus handling for drawers and dialogs.
overflow: clip
Prevents page-level horizontal overflow; local scroll containers remain available.

Fallback policy

Older engines should retain semantic document order, readable text, native form controls, and local table/code overflow. They may lose mixed surface colors, relational state styling, native popover behavior, balanced headings, or selected animation. FrameBaseCSS does not include polyfills and does not claim legacy browser support.
