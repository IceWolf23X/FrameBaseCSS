Interazione nativa

Accordion, tab statiche e procedure

FrameBaseCSS richiede JavaScript?

No. Accordion, popover e controlli base sfruttano primitive HTML.

Come si personalizza il tema?

Sovrascrivi i token --fb-color-*, --fb-space-* e --fb-radius-*.

  1. Collega il CSS
    Usa un file locale o un tag style.
  2. Scrivi HTML semantico
    Aggiungi classi solo per il layout.
  3. Personalizza i token
    Mantieni invariati i componenti.
