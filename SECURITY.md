# Security policy

## Supported versions

Security fixes are provided for the latest released minor version. Until a
newer stable line exists, the current `1.x` release line is supported.

| Version | Supported |
|---|---|
| Latest `1.x` | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability. Use the repository
Security tab and select **Report a vulnerability** to start a private GitHub
Security Advisory with the maintainers:

<https://github.com/IceWolf23X/FrameBaseCSS/security/advisories/new>

Include the affected asset and version, a minimal reproduction, expected impact,
and any known workaround. Please allow the maintainers time to validate and
coordinate a fix before public disclosure.

## Security scope

FrameBaseCSS has no required runtime JavaScript and does not process credentials
or user data. Security reports can still include supply-chain or package
integrity issues, unsafe documentation that enables script injection, CSS that
obscures security-relevant controls, dependency vulnerabilities in maintainer
tooling, or published assets that differ from reviewed source.
